# Technologies

## Python

Python is the primary programming language used by Nexora Technologies for artificial intelligence, machine learning, data science, and backend development.

## LangChain

LangChain is used by the Artificial Intelligence Department to develop applications powered by large language models.

It is used in the InsightAI project for document processing, retrieval pipelines, and LLM integration.

## LangGraph

LangGraph is used in the InsightAI project to build stateful and multi-agent AI workflows.

## Azure OpenAI

Azure OpenAI provides large language model capabilities for Nexora Technologies' AI applications.

It is used by InsightAI and ClientAssist.

## FastAPI

FastAPI is a Python framework used to develop backend APIs.

The ClientAssist project uses FastAPI for its backend services.

## React

React is used to build frontend user interfaces.

The ClientAssist project uses React for its customer support interface.

## PostgreSQL

PostgreSQL is a relational database used for storing structured application and business data.

It is used by InsightAI and ClientAssist.

## Docker

Docker is used to package applications and their dependencies into containers.

The DevOps team uses Docker for application deployment.

## Pandas

Pandas is a Python library used for data manipulation and analysis.

The Customer Analytics project uses Pandas for data preprocessing and analysis.

## NumPy

NumPy is used for numerical computing and data processing in the Customer Analytics project.

## Scikit-learn

Scikit-learn is a machine learning library used by the Data Science Department.

Customer Analytics uses Scikit-learn to develop customer churn prediction models.
