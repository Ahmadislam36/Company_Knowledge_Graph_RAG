# Projects

## InsightAI

InsightAI is an internal AI platform developed by Nexora Technologies.

The project is managed by Hamza Salman and technically led by Sara Khan.

Ahmed Islam works on InsightAI as an AI Engineer.

The project uses Python, LangChain, LangGraph, Azure OpenAI, PostgreSQL, and Docker.

InsightAI provides document question answering, RAG-based search, and multi-agent workflows.

The project uses Azure OpenAI for large language model capabilities.

LangChain is used for LLM application development and retrieval pipelines.

LangGraph is used to build stateful multi-agent workflows.

PostgreSQL is used for structured application data.

Docker is used to package and run application services.

## Customer Analytics

Customer Analytics is a data science project for analyzing customer behavior.

Ali Raza works on the project as a Data Scientist.
